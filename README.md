# San Diego CCD — TRACE Project Dashboard

Project dashboard for the **San Diego Community College District (SDCCD)** initiative
**TRACE: Transparent Recruitment & Accountability for Candidate Equity** — a **$149,997
Tier 1 award** under the 2026–2028 Equal Employment Opportunity Innovative Best Practices
(EEO IBP) grant initiative (NOVA application #30555).

The dashboard mirrors the structure of the Antelope Valley CCD dashboard and is populated
entirely with SDCCD's factual grant-application data.

## What's here

- **`index.html`** — the complete, self-contained single-file dashboard (HTML + CSS + JS).
  No build step. Open it directly or serve the folder statically.
- **`sdccd-logo-sidebar.svg`** — sidebar logo: the SDCCD sunburst mark (district
  cyan plus the four colleges' colors) with the "San Diego Community College
  District" wordmark. `sdccd-favicon.svg` / `sdccd-favicon-32.png` are the
  matching sunburst favicons.
- **`Bulle Cloud Logo-white.png`** — grant-monitor logo (Bulle Consulting).

## Sections

| Section | Contents |
|---|---|
| **Overview** | Headline KPIs ($149,997 Tier 1, 6 goals, 6+12 qualitative inputs, 4+4 colleges/sites), program spotlight, budget-by-object-code charts, project summary table |
| **Goals & Objectives** | All six TRACE project goals with activities, measurable outcomes, and assessment plans (workplan §2.1) |
| **Project Profile** | Hero summary, six goals, "Why This Project," workplan activity clusters A–H, institutional resources, three standing sub-committees |
| **Budget Breakdown** | Object-code budget ($149,997 total, $7,142 / 5% indirect) split across Year 1 / Year 2, plus an interactive Budget Modification Request form with an animated training guide |
| **Timeline** | Year-by-year spend profile and phased timeline with responsible persons (workplan §2.4) |
| **Contacts** | Project lead, alternate lead, fiscal reporter, and plan approver |
| **Spend-Down Monitor** | Fiscal-year line items (FY 2025-26 / 2026-27 / 2027-28) with per-line spend pace, status toggles, and underspend-risk alerts |
| **Forms** | Grant Modification and Budget Modification request forms |

## Key figures (from the grant application)

- **Total award:** $149,997 (Tier 1) — direct $142,855 + indirect $7,142 (5%)
- **Cycle:** Jan 1, 2026 – Jun 30, 2028 (two performance years; three fiscal years)
- **Year 1 / Year 2:** $89,998 / $59,999
- **Object codes:** 1000 Instructional Salaries, 2000 Non-Instructional Salaries,
  4000 Supplies & Materials, 5000 Other Operating & Services, 7000 Indirect

## Features

Responsive layout, light/dark theme, six-language translation (EN/ES/VI/AR/TL/ZH with RTL
support), full accessibility panel (contrast, dyslexia font, text sizing, reduced motion,
reading guide), and localStorage persistence for budget-form entries and spend-pace toggles.
